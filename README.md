# Incremental Ingestion Engine（Go，本地文件模拟）

一套本地可运行的增量数据摄入与落地流程：用本地文件模拟数据源（事件日志）与目标端（物化表），
使**重复消费、位点回退、来源结构变化**下的最终数据状态可预期、可解释。仅依赖 Go 标准库。

## 能力

- **变更采集与落地**：`insert / upsert / delete`；主键冲突、必需字段缺失、类型不匹配、
  缺主键、载荷含未声明字段等坏记录按**可区分原因**拒绝并留痕，绝不静默丢弃；
  同批数据重复运行（含消息重投、进程重启）目标端无重复、无丢失。
- **断点与并发协同**：worker 并发处理、位点按 seq 串行提交；已提交位点严格单调，
  只接受 `committed+1`，回退/跳段显式拒绝；位点 fsync 落盘，中断后从最近已提交位点恢复。
- **结构变化兼容**：新增字段的缺省语义确定且稳定（默认值或 nullable→nil），历史行自动回填；
  删字段/改名/改类型/改主键等无法安全兼容的变化显式失败并在结构历史中留痕，不静默错列。
- 全程落盘：事件日志、物化表、位点、拒绝记录、变更流水、结构变更历史（见 `data/`）。

## 快速开始

```bash
go run ./cmd/demo        # 端到端演示：造数 -> 并发摄入 -> 重投 -> 结构变更 -> 重启恢复
go test -v ./...         # 单元测试（日志含位点、提交顺序、变更流水）
go test -race ./...      # 含竞态检测
```
